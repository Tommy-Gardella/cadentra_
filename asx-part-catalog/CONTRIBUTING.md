Contributing
============

How to edit this project

Possible interpretations of "allow Claude to edit":

1) Claude is a human collaborator (GitHub account)
- Create a GitHub repo for this project and invite the GitHub username or email for "Claude" with write access.

2) Claude is the Anthropic Claude AI (agent)
- You can use Anthropic's file upload or a plugin that exposes the workspace to Claude. Provide API credentials and instructions for the specific Claude product (e.g., Claude 2, Claude Instant).

3) Claude is an assistant running in VS Code (local)
- Use a VS Code extension that exposes files to an assistant, or run the Claude agent locally with file-system access. Configure access per the extension's docs.

What I need from you
- Which "Claude" do you mean? (GitHub user, Anthropic Claude, VS Code assistant, other)
- If GitHub: provide the username or email to invite.
- If Anthropic or a plugin: provide preferred integration details.
